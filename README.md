# TargetFactory — лендинг

Статическая версия лендинга агентства Target Factory (продвижение ВКонтакте).
Исходник — страница https://deford.ru/targetfactory/, обновлённая по макету Figma
«TargetFactory – цветочные (tf-flowers)», страница «Сайт TargetFactory (копия deford.ru)».

## Что изменено относительно исходной страницы

По десктопному макету переделаны три блока, остальные оставлены без изменений:

- **«8 причин доверить продвижение нам»** — карточки без фото, полупрозрачные, с номерами 01–08;
  кнопка «Получить консультацию».
- **«Выбирайте формат сотрудничества»** (тарифы) — одна карточка на тариф без иконок-объектов;
  цена «Продвижение под ключ» — 50 000 ₽/мес.
- **«Почему выбирают нас»** — сетка 4 колонки с большим фото по центру и CTA-карточкой.

Стили новых блоков — `_astro/redesign.css` (мобильная и планшетная адаптация там же).

## Структура

```
index.html          страница
_astro/             стили и скрипты (собраны Astro, минифицированы) + redesign.css
img/                изображения
```

## Запуск

Сборка не нужна — достаточно открыть `index.html` или раздать папку любым статическим сервером:

```
python3 -m http.server 8000
```

Формы заявок отправляются в Tilda (`forms.tildacdn.com`), как и на исходной странице.
